# Java Alarm Clock

A lightweight, console-based digital alarm clock application written in Java. This project lets users set a specific target time, tracks the current system time dynamically, and plays an audio file notification when the alarm triggers.

## 🚀 Features
* *Custom Alarm Settings:* Input your desired target time directly via the command-line console.
* *Live Dynamic Tracking:* Constantly tracks system time using Java's built-in date-time API elements (java.time).
* *Audio Alerts:* Automatically triggers a custom audio notification (.wav sound clip) when the set time matches the system clock.

## 🛠️ Built With
* *Java SDK* - Core application logic and execution.
* *Java Time API* - Handles internal time calculations and parsing structures.
* *IntelliJ IDEA* - Integrated Development Environment (IDE).

## 📋 Prerequisites
Before running the application, make sure you have the Java Runtime Environment (JRE) or Java Development Kit (JDK) installed on your system.

## ⚙️ How to Run
1. Open the project files in your preferred Java IDE (such as IntelliJ IDEA or Eclipse).
2. Ensure your custom audio file (VibeFire - Jessie Villa.wav) is placed properly inside the project root path.
3. Run the main project execution loop from Main.java.
4. Follow the console prompt inputs to specify your alarm target configuration.
